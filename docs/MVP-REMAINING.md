## 明确**不进** MVP 首版（已拍板，归后续）

- 真·账号 / 云端 / 跨设备同步、真好友系统与动态流（首版纯本地、无后端；当前仅"本地社交-lite"明信片联系人）。
- 视频上传（≤3min）→ 归 Plus / 快速跟进。
- 明信片"寄出/送达统计"→ 依赖云端真送达确认，本地无法判定，记入需求池。
- RevenueCat → 抽象层已留口，上 Android 时再替换 `PlusStore` 内部。
- 地图皮肤 / 进阶统计·年度回顾 → Plus 后续权益。
