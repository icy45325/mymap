# Lumi v0 — 世界点亮 MVP
**功能规格说明 · v0.2（工程就绪）**

> 适用范围：Lumi 最小可行切片（v0）。目标是验证产品最大风险假设，而非交付完整产品。完整产品蓝图见《Lumi 产品与架构总览》。
> 线框稿：本 PRD 各 UI 章节对应 Axure 页面 `Lumi/v0/[页面名]`（人工维护）；交互示意图见《总览》第 12 章「UI 原型」。

---

## 1. 背景与问题描述

Lumi 是一款以"在地图上点亮去过的地方"为核心的个人旅行记录产品，定位于现有竞品最弱的「记忆 / 共创」象限。完整形态包含交换日记、AI 故事片、共创圈子等，但这些都建立在一个尚未验证的前提之上：

**用户是否愿意手动记录每一个足迹？点亮那一下是否足够爽，以至于愿意持续记？**

这是整个产品最大的风险假设。v0 的唯一使命是验证它，因此刻意砍到只剩核心回路。第一用户为作者本人，正在 UAE 旅行，具备天然的 dogfood 条件。

---

## 2. 目标

**v0 产品目标**
- 跑通核心回路：**录入足迹 → 地图点亮 → 计数器即时反馈**。
- 让"点亮"产生即时收集快感（集邮回路）。

**成功信号（验证标准）**
- 作者本人连续 ≥ 2 周、平均每天自发打开并记录 ≥ 1 个足迹。
- 达成则回路成立，进入 v0.x（交换日记 / 怀念回路）；未达成则修回路本身，而非加功能。

**非目标**：见 §8。

---

## 3. 功能范围

v0 为单一场景：**单用户 · 单端（iOS）· 纯本地**。无账号、无网络、无多人。包含四个功能模块，均为全新功能（无存量变更）。

| 模块 | UI | 逻辑 | 说明 |
|---|---|---|---|
| ① 地图主页 MapHome | 是 — 暗夜世界地图 + 点亮着色 + 顶部计数器 | 是 — 点屏选点、point-in-polygon 解析、点亮判定 | 核心页 |
| ② 录入·明信片卡 Capture | 是 — 照片 + 地点 + 心情 + 同行人 + 点亮按钮 | 是 — 落库 Footprint、生成 Card、触发点亮 | 核心流程 |
| ③ 足迹时间轴 Timeline | 是 — 倒序卡片流 | 是 — 按 visitedAt 排序读取 | 回顾入口 |
| ④ 点亮成就 Stats | 是 — 大数字 + 各洲进度 + 徽章 | 是 — 聚合统计已点亮国家/区域 | 集邮满足感 |

## 4. UI 设计规格

> 设计基调：暗夜地图 + 琥珀点亮（`#F6B43E`）。示意图见《总览》§12。

### 4.1 地图主页 — MapHome
> 线框稿见 Axure「Lumi/v0/MapHome」，与本节 §4.1 对应。

- 全屏暗色世界地图（MapKit，`.standard(elevation: .flat)`）。
- 已点亮区域以琥珀色半透明填充（透明度 0.32）+ 描边。
- 足迹点显示为发光小圆点。
- 顶部常驻**计数器 chip**：`✦ 已点亮 X 国 · 全球 Y% · Z 城`。
- 底部 Tab：地图（默认选中）/ 足迹 / 成就 / 我。
- 右下角悬浮主按钮「+ 点亮新足迹」→ 进入 4.2。

### 4.2 录入·明信片卡 — Capture
> 线框稿见 Axure「Lumi/v0/Capture」，与本节 §4.2 对应。

单屏完成，自上而下：
1. **照片区**：从相册选 1 张（v0 仅 1 张）。
2. **地点**：`MKLocalSearch` 搜索 + 当前定位建议；显示 placeName。
3. **日期**：默认今天，可改。
4. **一句心情**：单行输入，placeholder「记一句此刻的感受…」。
5. **同行人**：chip 输入，可加多个（自由文本）。
6. 底部**主按钮「点亮这里 ✦」**：常驻可见，琥珀渐变。

点击「点亮这里」→ 保存 Footprint（同时**持久化一张 Card 明信片卡**）→ 返回地图 → 目标区域点亮动画 + 计数器跳动。

### 4.3 足迹时间轴 — Timeline
> 线框稿见 Axure「Lumi/v0/Timeline」，与本节 §4.3 对应。

- 顶部统计行：`年份 · 已记录 N 段`。
- 倒序（visitedAt desc）卡片流，每条：缩略图 + 地点名 + 日期 + 同行人摘要。
- 点击一条 → 明信片卡详情（只读，v0 不做编辑也可接受，详见 §7）。

### 4.4 点亮成就 — Stats
> 线框稿见 Axure「Lumi/v0/Stats」，与本节 §4.4 对应。

- 顶部大数字：`已点亮国家数` + `全球百分比`。
- 徽章行：里程碑徽章（如「首个海外国家」「沙漠之国」）。
- 各大洲进度条（已点亮 / 该洲国家总数）。

## 5. 核心逻辑 / 状态机

### 5.1 点亮判定流程

```
[用户在地图点屏 或 在录入页确认地点]
        │
        ▼
[得到 WGS-84 坐标]
        │
        ▼
[point-in-polygon 解析] ──落在某国──> [得到 countryCode]
        │                                   │
   落在公海/无匹配                      [该国是否已点亮?]
        │                              ├─ 否 ─> [新增点亮 + 计数 +1 + 动画]
        ▼                              └─ 是 ─> [不重复计数，仅累加该国足迹数]
[提示「未能识别所在国家，
 请手动选择」]
```

- **国家级点亮**：基于 `Footprint.countryCode`。
- **UAE 下钻**：当 `countryCode == "AE"` 时，进一步解析 `subRegionCode`（酋长国），酋长国级单独点亮（边界数据用 **Natural Earth admin-1**）。其余国家 v0 不下钻。
- **城市为点状打卡**：城市（含后续英国的城市下钻）以**足迹 pin** 呈现、按 `distinct(cityName)` 计数，**不做区域着色**；区域着色只用于国家级与 UAE 酋长国级。
- **计数口径**：已点亮国家数 = `distinct(countryCode)`，同国多次到访不重复计数；已点亮城市数 = `distinct(cityName)`。

### 5.2 录入状态机

```
[草稿 Draft]
   │ 选照片 / 填地点
   ▼
[填充中 Filling] ──点「点亮这里」──> [已保存 Saved]
   │                                      │
   │ 中途退出                              ▼
   ▼                               [触发地图点亮 + 计数]
[丢弃 Discarded]（埋点 capture_abandoned）
```

## 7. 边界情况处理

| 情况 | 处理方式 |
|---|---|
| 无相册权限 | 允许跳过照片，仍可录入（照片非必填）；引导去设置开启 |
| 无定位权限 / 拿不到定位 | 退化为手动搜索地点（MKLocalSearch），不阻断录入 |
| 坐标落在公海 / 无国家匹配 | 提示「未能识别所在国家，请手动选择」，提供国家列表兜底 |
| 同一国家重复到访 | 不重复计数，仅累加该国足迹数；地图保持点亮 |
| 用户从系统相册删除了照片 | `photoAssetID` 失效 → 卡片显示占位图，不崩溃；**待确认**清理策略（见文末） |
| 离线 | v0 纯本地，全功能可用（搜索地点除外，MKLocalSearch 需网络） |
| 应用被杀 / 重启 | SwiftData 已落库，数据不丢 |
| 时间轴编辑 / 删除足迹 | v0 至少支持**删除**；编辑可后置（**待确认**） |

## 8. 非目标（Not in Scope）

v0 明确不做，避免稀释核心验证：

- 交换日记、AI 旅行故事片、怀念回路（去年今日 / 年度回顾）
- Web 端、圈子社区、任何分享 / 导出
- 省 / 市级下钻（仅 UAE 下钻到酋长国）
- 云同步、推送通知、账号体系（→ 这些一旦要做即需付费 Apple Developer Program）
- GPS 后台自动记录
- 多张照片、视频、语音、涂鸦
- 国内合规底图（高德）与审图号（仅在国内分发时启动）

## 10. 验收标准

**① 地图主页**
- [ ] 启动后显示暗色世界地图，已点亮国家以琥珀色填充
- [ ] 顶部计数器实时显示已点亮国家数、城市数与全球百分比
- [ ] 新增足迹后，对应国家在地图上点亮、计数器 +1

**② 录入·明信片卡**
- [ ] 可从相册选 1 张照片（或跳过）
- [ ] 可搜索并选定地点，自动带出 placeName
- [ ] 可填写一句心情与多个同行人
- [ ] 点「点亮这里」后足迹落库，返回地图并触发点亮
- [ ] 保存足迹时同步生成并持久化一张明信片卡（Card）

**③ 足迹时间轴**
- [ ] 按 visitedAt 倒序展示所有足迹卡片
- [ ] 每条显示缩略图、地点、日期、同行人
- [ ] 支持删除一条足迹，删除后地图与计数同步更新

**④ 点亮成就**
- [ ] 大数字与全球百分比与地图数据一致
- [ ] 各大洲进度条数值正确（已点亮 / 该洲总数）

**数据与稳定性**
- [ ] 杀进程重启后数据不丢
- [ ] 同一国家重复到访不重复计数
- [ ] 坐标无法识别国家时有兜底手选，不崩溃

## 设计决策

**已确认（v0.2）**
- ✅ **英国"城市"下钻 = 点状打卡**：城市以足迹 pin 点亮、按 `distinct(cityName)` 计数，不做区域着色。该规则对所有国家的城市通用（英国下钻本身仍排在 v0 之后）。
- ✅ **UAE 酋长国边界 = Natural Earth admin-1**。
- ✅ **明信片卡持久化**：每个 Footprint 录入时同步建一张 Card（见 §4.2 与数据模型 Card）。

**仍待确认（不自行假设）**
1. **photoAssetID 失效策略**：照片被删后占位即可，还是提示补图 / 自动清理该足迹的照片引用？
2. **时间轴编辑**：v0 是否需要编辑已有足迹，还是只支持删除 + 重录？

### 12.1 收集品总览

| 类别 | 数量 | 获取条件 | 使用限制 | 载体 |
|------|------|---------|---------|------|
| 基础邮票（**普通邮票**：空运✈️/陆运🚆/海运⛴️） | 3 | 默认解锁 | 任意明信片 | 明信片背面邮票位 |

| 典藏邮票（Plus） | 14（CN×3 / US×3 / JP×4 / AE×4） | **终身会员** + 点亮该国 | 仅限该国足迹；**AE 再绑酋长国**（迪拜 `AE-DU` 只见哈利法塔，阿布扎比 `AE-AZ` 见另 3 枚；足迹无酋长国码时放宽为全国） | 同上 |

### 12.2 邮票选择器规则（寄明信片时）

选择器组成（按序）：**基础三款 → 本国地区票（目录内才有）→ 窗口期内节日章 → 匹配的典藏票**。

- 非 Plus 用户：典藏票只露**前 2 枚**、带锁 + PLUS 徽记，点击弹 Paywall（付费入口），不可选中。
- 权益回落守卫：非 Plus 状态下已选中的典藏票在重渲染时**自动回落为基础空运**，不可能寄出。
- 收件方：**无条件按票面显示**（卡面体现发送方权益，与收件人是否 Plus 无关）。

**编码口径**（存于 `Footprint.stampStyle` 并随口令 payload 传达，未知值兜底空运）：

| 类别 | raw 编码 | 例 |
|------|---------|----|
| 基础 | `air` / `land` / `sea` | `air` |
| 地区 | `cc:<ISO2>` | `cc:JP` |
| 典藏 | `prem:<id>` | `prem:ae_burj` |
| 节日 | `fest:<id>` | `fest:christmas` |

### 12.3 节日章窗口与地区归属（判定用「寄卡当天」，按公历月-日，逐年复用）

| 节日章 | 基准日 | 可用窗口（±5 天，含端点） | 适用足迹地区 |
|--------|--------|--------------------------|--------------|
| 先知诞辰 | 8/25 | 8.20 – 8.30 | 中东 |
| 阿联酋国庆 | 12/2–12/3 | 11.27 – 12.8 | 中东 |
| 感恩节 | 11/26 | 11.21 – 12.1 | 欧美 + 亚洲（不含中东） |
| 圣诞节 | 12/25 | 12.20 – 12.30 | 欧美 + 亚洲（不含中东） |
| 中秋 | 9/25–9/27 | 9.20 – 10.2 | 中国 |
| 中国国庆 | 10/1–10/7 | 9.26 – 10.12 | 中国 |

- 地区口径：中东 = AE/SA/QA/KW/BH/OM/JO/LB/IQ/YE/SY/PS/IR；中国足迹除中秋/国庆外也可用欧美+亚洲组节日。
- 图鉴「已收集」= 收到过贴该章的明信片（`fest:` 前缀）；旧版收到卡按 地区 × 寄出日期 兜底判定。

### 12.4 邮戳 Postmark（邮局章）

- **独立类目**（与邮票平行），当前仅**通用 LUMI 圆戳**一枚：城市名前 3 字母大写 + 年份缩写，随明信片样式配色。
- **寄出 / 分享前不盖**；视作真实邮寄时邮局所盖，**仅收件人翻面可见**。
- **未来方向（💡）**：为终身会员扩充更多邮戳，按 **国家 / 地区 / 节日** 区分（复用地区匹配与节日窗口期机制）；图鉴已预留独立「邮戳」分区与占位。

### 12.5 护照入境章

- 每个去过的国家自动生成一枚入境章（圆 / 方 / 椭圆章型随国家；ADMITTED + 口岸 + 日期）。
- **交通方式三态**（航空✈️ / 陆路🚆 / 海运⛴️）来自足迹 `entryMeans`：点亮、编辑、入境章详情内均可切换，
  持久化到**该国最早一条足迹**；章面图标与详情行随之变化。
- 入境章详情浮层带**逐国地标暗纹**：12 国专属地标（GB 大本钟 / CN 长城 / US 自由女神 / SG 鱼尾狮为手绘矢量，
  其余为 SF Symbol），未覆盖国家用地球图案兜底；低不透明度斜向平铺，不抢内容。

### 12.6 收集图鉴（Me 页入口）

- 四分区共 **36 件**：地区邮票 12 + 典藏邮票 14 + 节日章 6 + 基础邮票·邮戳 4；顶部进度环「已收集 X / 36」。
- 解锁口径**全派生、零新增存储**：地区 = 点亮该国；典藏 = Plus 且点亮该国；节日 = 收到过贴该章的卡；基础/邮戳 = 默认。
- 点任意条目 → **半屏详情弹窗**：放大贴图 + 解锁/收集状态 + 使用限制 + 用法；非 Plus 的典藏票详情底部带「成为终身会员」按钮直达 Paywall。
