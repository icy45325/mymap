## 1. 测试准备

- [ ] **Release 配置**编译（不是 Debug-only 路径），真机安装；**先删旧包**再装（清小组件 / 图标缓存）。
- [ ] StoreKit 本地测试：Scheme → Run → Options → **StoreKit Configuration = `Lumi.storekit`**（或用沙盒账号）。
- [ ] 造一份**示例数据**：点亮 ≥ 8 个国家、≥ 12 个城市，含 1 条多图(≥3 张)足迹、1 条多天行程、1 条带心情/同行人的足迹。
- [ ] 准备**第二台设备**（或同机 Safari）用于明信片收发。
- [ ] 准备相册：设备相册里有**带定位**的照片（用于导入）。
- [ ] 三语切换方式：iOS「设置 › Lumi › 语言」分别切 简体中文 / English / العربية。

---

## 2. 冒烟（每语言各 3 分钟，先快过一遍）

- [ ] 启动不崩；四个 Tab（地图/星迹/成就/我）都能进、能回。
- [ ] 地图点亮一个国家 → 星迹出现该条 → 成就/小组件计数 +1。
- [ ] 打开一条足迹详情 → 「邮寄明信片」面板能出图。
- [ ] 设置页能开；Lumi Plus 升级页能开。
- [ ] 切到另一语言重启，文案随之变化、无错位。

> 冒烟任一项崩溃/严重错位 → 停下修，不继续细测。

## 3. 分模块回归

### A. 启动 & 导航
- [ ] 冷启动 < 2s 进首页；地图 Tab 默认选中。
- [ ] 四 Tab 来回切换不卡、不丢状态。
- [ ] 深色外观正确（全 App `.dark`）；状态栏文字可见。

### B. 地图与点亮
- [ ] 真实地图可缩放/平移；已点亮国家有着色。
- [ ] 点一个**未点亮**国家 → 提示选城市列表（可不选）→ 选年份 → 点亮成功。
- [ ] 点一个**已点亮**国家 → 显示「已点亮 · 再记一次」可用。
- [ ] 城市列表「开关式」选择正常；默认不选不报错。
- [ ] 点亮后：星迹 / 成就 / 小组件数字一致（口径统一）。

### C. 星迹时间线 & 详情 & 编辑
- [ ] 顶部「今年 N 国 M 城」统计正确（与示例数据吻合）。
- [ ] 按年份分组、倒序展示；地区筛选分段可用。
- [ ] **详情页通栏**：顶部照片墙铺到屏幕顶部，**状态栏区不是黑条**；返回/编辑按钮避开状态栏。
- [ ] **多图**：左右可滑；**每 3.5s 自动翻页**；右下角「当前/总数」提示正确。
- [ ] 单图足迹不显示翻页指示，无空白。
- [ ] 编辑：改地点名/日期/心情/同行人 → 保存生效；替换/增删照片正常；单条 ≤ 21 张限制生效。
- [ ] 长按卡片 → 删除确认 → 删除后列表/计数同步。

### D. 相册导入
- [ ] 星迹「从相册同步」→ 首次弹相册权限。
- [ ] **加载期**只显示 loading，不闪「128 → 去重」过程；结果**已去重**逐条出现。
- [ ] **按城市 / 按国家**切换**即时**（不重扫、不反复刷）；**国家列表非空**。
- [ ] 城市名只到城市级（无区/街道/POI）。
- [ ] 已导入项默认不勾选；勾选导入后入星迹，计数同步。
- [ ] 拒绝权限 → 显示去设置引导；无定位照片 → 空态文案正确。

### E. 成就 / 徽章
- [ ] 徽章墙蜂巢无遮挡；锁定/解锁态对比清晰。
- [ ] 点已解锁徽章 → 详情（是什么/稀有度/持有率）；点「即将解锁」→ **不**触发点亮动效。
- [ ] **新增足迹触发新解锁** → 弹庆祝卡（仅新解锁那次）；分享徽章出图。
- [ ] 置顶 / 取消置顶可用。

### F. 心愿单
- [ ] 「我的」→ 心愿单入口可进。
- [ ] 添加心愿：搜索添加正常；**搜索为空时显示「还没去过的热门目的地」预设**（已排除去过/已心愿）；点一下加入。
- [ ] 地图点选标记心愿正常；删除心愿正常。

### G. 明信片 · 发送
- [ ] 详情页 →「邮寄明信片」打开面板，预览即时出图。
- [ ] 寄语默认生成、可改；手写体显示正常（中/英/阿各看一次）。
- [ ] 主按钮「邮寄明信片」→ 系统分享面板（含 AirDrop / 信息等）。
- [ ] 「复制链接」「二维码」「隔空投送」三入口都可用。
- [ ] **免费态**：预览/导出带 **Lumi 水印**；面板有「升级去水印」提示条。

### H. 明信片 · 接收（四渠道）& 明信片墙
- [ ] **链接**：把 `lumi://…` 链接在 Safari/信息点开 → 进 Lumi 弹「收到一张明信片」→ 收下入星迹。
- [ ] **系统相机扫码**：扫二维码 → 弹「在 Lumi 打开」→ 收下。
- [ ] **应用内扫一扫**：星迹页扫码入口 → 扫码 → 收下（仅相机权限路径）。
- [ ] **隔空投送**：AirDrop `.lumicard` → 选「用 Lumi 打开」→ 收下。
- [ ] **剪贴板**：复制口令后进 App → 自动识别弹收下。
- [ ] **幂等**：同一明信片各路径**只收一次**；发送方自己不被弹「收到」。
- [ ] 明信片墙：只展示**收到的**；自己点亮/寄出的不在墙上；空态文案正确。

### I. 护照本
- [ ] 「我的」→ 护照本入口可进。
- [ ] 封面按**国籍配色**；个人信息页（头像/姓名/国籍/去过国家汇总）正确。
- [ ] 盖章页可前后翻页；去过国家有入境章；空态（无足迹）文案正确。

### J. 个人资料
- [ ] 「我的」头像入口 → 编辑：上传头像 / 改昵称 / 选国籍 → 保存。
- [ ] 改国籍后护照封面与个人信息页随之更新。

### K. 小组件（主屏 / 锁屏）
- [ ] 添加「Lumi 战绩」小组件；**长按 → 编辑小组件 → 切换 点亮战绩 / 去过的国旗**。
- [ ] **国旗长条**：铺满去过国家国旗 + 「已点亮 N 国 · M 城」+ 一句话；**国旗数量与 App 内一致**（非只剩最近几个）。
- [ ] 「点亮战绩」「去年今日」展示正确；新增足迹后小组件刷新。
- [ ] **小组件文案跟随系统语言**（切英/阿后小组件随之变）。
- [ ] 锁屏小组件（若支持族）正常。

### L. Lumi Plus / Paywall / IAP　🔑 提审重点
- [ ] 设置页「Lumi Plus」行 / 明信片「升级」条 → 打开 Paywall。
- [ ] Paywall 显示三档价格（**月/年/终身**），价格来自配置（非空白）；年付显示「省 %」。
- [ ] 购买月订 → 成功 → `isPlus` 生效 → 明信片**水印消失 + 高清(3x)**；升级条/设置行变「已解锁」。
- [ ] **杀进程重开仍是 Plus**（entitlement 对齐）。
- [ ] 「恢复购买」可用（先在测试环境清除购买再恢复）。
- [ ] 取消购买弹窗 → 不误判为已购买。
- [ ] 终身买断购买 → 永久 Plus。
- [ ] Paywall 自动续订条款文字在场；隐私/条款链接能打开（见 §5）。

### M. 设置
- [ ] 小组件介绍区文案正确；预览三种小组件样式不错位。
- [ ] 「语言跟随系统」跳系统设置可用。

## 4. 三语 & 阿语 RTL 专项　🔑 提审重点

> 关键路径在**每种语言**各走一遍：点亮 → 星迹 → 明信片发送 → 设置/Paywall。

- [ ] **简体中文**：全流程文案完整，无英文兜底、无 `key` 字样。
- [ ] **English**：全流程文案完整、无中文残留、无截断溢出。
- [ ] **العربية（阿语）**：
  - [ ] 整体布局**镜像（RTL）**：返回箭头、列表方向、分段控件方向正确。
  - [ ] 箭头/方向性 icon 已镜像（`flipsForRightToLeftLayoutDirection`）。
  - [ ] 数字 + 阿语混排不串位；明信片手写体（Farah）正常。
  - [ ] Paywall / 明信片 / 护照 / 小组件文案完整无溢出。
- [ ] 三语下日期 / 国名 / 计数单位（国/城/洲）本地化正确。

## 6. 稳定性 & 边界

- [ ] **杀进程 / 后台→前台**：状态、Plus、小组件数据不丢不乱。
- [ ] **空态**：全新安装（无任何足迹）四 Tab 都有合理空态，不崩。
- [ ] **大数据量**：点亮 50+ 国家后，地图 / 星迹 / 国旗小组件不卡死、不截断错误。
- [ ] **无网络**：飞行模式下点亮、看星迹、发明信片（成图/二维码）仍可用；地点搜索/反编码降级不崩。
- [ ] **权限全拒**：相册/位置/相机全拒后，相关入口给引导而非崩溃。
- [ ] **旋转 / 动态字体**（若支持）：主要页不破版。
- [ ] 反复进出明信片面板 / Paywall 无内存泄漏式卡顿。
