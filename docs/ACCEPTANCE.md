## 4. 护照本
- [ ] 进入后**无**顶部「护照本/我的旅行护照」标题、**无**底部「封面/资料页/入境章」说明文字，只有进度点

- [ ] 资料页信息**更大**、占比舒服（姓名/国籍/签发 + N 国已点亮 + 国家码 + MRZ）
- [ ] 入境章页盖章、点章弹详情浮层（盖章动效 + 信息卡）
- [ ] 封面按**国籍配色**；改个人资料国籍后封面随之变
- [ ] **未设个人信息** → 护照页空状态「添加个人信息」→ 进资料页设置
- [ ] 护照风格（拟真/星夜）在**个人资料**首次设置可选 + **设置页**可切；护照页内无风格切换
- [ ] 「我的」页护照本入口与明信片墙/心愿单**同款卡片样式**（不再深蓝+金）

## 5. 心愿单
