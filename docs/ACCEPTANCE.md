> 这些是你上轮标 ✗ 的问题，已改完，重点复验。

### A. 🔴 中文系统显示英文（语言根因）
- [x] 系统中文 → App **全中文**（界面 + 小组件）；英文系统 → 全英文；阿语 → 阿语 RTL；其余 → 英文
- 改动：字符串目录之前只写了 `en`/`ar`，**缺源语言 `zh-Hans` 显式值**，`developmentRegion=en` 时中文系统找不到中文资源就回退英文。现已给**每条**补上显式 `zh-Hans`（app + 小组件两个目录）。
- ⚠️ 若清装后中文系统仍显示英文 → 记下来，需我从构建层再查（可能 zh-Hans.lproj 未随包）。

### B. 🔴 阿语下「星迹」新增页时间显示中文「开始/结束」
- [x] 阿语系统：新增足迹页日期行显示阿语「البداية / النهاية」，不再是中文
- 改动：`CaptureView` / `FootprintEditView` 的 `dateRow` 标签参数是 `String`（逐字显示），改为 `LocalizedStringKey`（走本地化）。

### C. 设置页「语言」跳转
- [x] 点「语言跟随系统」→ 跳到 iOS「设置 › Lumi」页，**该页出现「首选语言」选项**可单独设
- 说明：`openSettingsURLString` 只能跳到本 App 的系统设置页（iOS 不允许直达语言子页），这是系统行为。**「首选语言」选项需 App 带多套本地化才会出现**——依赖上面 A 的 zh-Hans 修复，复验时一并确认该选项是否出现。

### D. 明信片正面：竖图支持
- [ ] 上传**竖图**时，明信片预览转为**竖版**（不再把竖图裁成横条丢内容） 「✗ + 整个明信片创建页面都变形了，图片竖版的特别大，需要限制一个屏幕内的尺寸e.g. 345px 之类的」
- [x] 竖版**背面**：上＝国家/地名 + 寄语，下＝邮票/邮戳 + 寄给
- [ ] 上传横图时仍是横版（原样）「✗ + 整个明信片创建页面都变形了，图片横版也特别大，需要限制一个屏幕内的尺寸e.g. 345px 之类的」
- 改动：`PostcardFlipCard` 检测封面高>宽 → 卡片比例转竖版 + 新增竖版背面布局。

### E. 星迹详情统计格子被长地区名撑高

- [x] 「照片」「国家」格变窄，中间「地区」格更宽
- 改动：`statRow` 固定行高 62、两侧格固定窄宽、地区名 `lineLimit(1)+minimumScaleFactor`。

### F. 设置页「反馈与建议」不暴露邮箱
