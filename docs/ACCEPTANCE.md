# Lumi 上架前验收报告（统一版）

> **怎么测**：Mac 上 **Clean Build（⇧⌘K）→ 删旧 App → 重装**，再按下表逐项过。
> 勾 `[x]` 通过；不过就在该行后写「✗ + 现象」。🔴=阻塞级，必须过。
> 三语：每个可见文案在 **中 / 英 / 阿（RTL）** 三种系统语言下各看一眼。
> 最后更新 **2026-06-29**。本表已把历轮验收合并为一份「发版前总清单」。

---

## A. 核心点亮回路（地图 / 录入 / 时间线）
- [ ] 点阵地球：点亮国家正确着色；计数 / 全球占比正确
- [ ] 录入「点亮这里」：搜索地点→选年份→落库；离线无网也能点亮（point-in-polygon 判国家）
- [ ] 时间线：列表 / 详情 / 编辑（地点名 / 日期 / 心情 / 同行人）正常；空态有图标+标题+副标题+CTA
- [ ] **多图自动翻页**：足迹详情上传 3 张（含竖图）→ 1→2→3 顺序翻，**不跳页、不卡两页之间**（曾「跳页」，已加 `flipGen` 代标记修复，**重点复验**）

## B. 成就 / 徽章 / 报告分享
- [ ] 成就页布局：统计汇总（X/193 UN + 国家/城市/大洲 + 大洲征服）在**上**，徽章墙在**下**
- [ ] 徽章排序：已点亮在前（按进度），未解锁在后；点击看「怎么得到」
- [ ] 徽章插画随界面语言：中→中文版 / 英→英文版 / 阿→阿语版；缺某语言回退底图（不空白）
- [ ] 徽章文案 == 图上印字（中/英/阿，如 环球旅人 / 初见曙光 / 七大洲全集）
- [ ] 多枚同时解锁：只弹一个「点亮了 N 个徽章」汇总（不列单名）；单枚仍大图+名称+分享
- [ ] 徽章置顶 / 取消置顶即时生效（有触觉）
- [ ] 🔴 **成就报告分享**：点「分享」→ **面板秒开**（先 spinner，世界地图异步渲染）→ 出报告图（去过 N 国 + 世界地图高亮 + UN/大洲/城市 + 落款，紫色霓虹主题）。**首次点击也应能出图**（启动已预热世界轮廓，重点复验冷启动）

## C. 心愿单 / 全屏地图国家操作
- [ ] 心愿单：搜索添加 / 删除；空态正常
- [ ] 🔴 **全屏地图点国家 → 一个半浮窗**整合：我去过这里（年/月+多城）、加入/已在心愿、看去过的城市入口、**推荐城市（一键心愿 / 一键点亮）**；操作后即时刷新
- [ ] 全屏地图配色：去过=粉、心愿=青（虚线），底部图例正确
- [ ] 「看看去过的城市」：列已去城市（名+日期+次数）+ 灰显没去过的预设城市

## D. 明信片（样式 / 邮票 / 收发 / 分享）
- [ ] 样式（复古/现代/插画）+ 邮票（空运✈️/陆运🚆/海运⛴️）选择即时预览；随口令传达；墙按样式呈现
- [ ] 朝向随图：上传横图→横版、竖图→竖版、无图默认横版；预览不变形
- [ ] 导出/分享图 = 照片 + 背面寄语 + 邮票（横图横版 / 竖图竖版）
- [ ] 免费态带 Lumi 水印；Plus 去水印高清（3x）
- [ ] 「寄给」下方往来联系人 chips，点一下填入
- [ ] 收发闭环：口令 / 二维码 / 链接 / AirDrop 任一 → 对方在 Lumi 自动收下（有触觉）
- [ ] 🔴 **分享与 Instagram 同一排**：「邮寄明信片」+ 紧凑 IG logo 按钮；**没装 IG 时分享占整行**
- [ ] 分享到 Instagram → 进 **Feed 发帖编辑器**，图清晰、原比例不裁切（装了 IG 才显示）
- [ ] （单机受限）明信片墙顶部「往来的人」头像横条 — 需两台机验证，留到 TestFlight

## E. 护照本
- [ ] 资料页按国籍生成；封面风格（拟真 / 星夜）可切换
- [ ] 整页放大 / 翻页正常；空态（无个人信息 / 无入境章）正常
- [ ] 🔴 **入境章区分航空/陆地/海**：章面图标与详情「入境方式」随足迹邮票样式显示 空运✈️/陆运🚆/海运⛴️（三语：空运/陆运/海运入境）

## F. 小组件 / 个性化展示台
- [ ] 三种小组件（点亮计数 / 去年今日 / 去过的国旗）真机添加可用；文案跟随系统语言
- [ ] 设置页「个性化 → 小组件 & 样式」展示台：①小组件轮播（每个含**小方块 + 一横条**两种预览，左右滑切换）②护照风格画廊（迷你护照封面占位图）
- [ ] 「添加到桌面」→ 弹图文指引（4 步 + 当前 widget 名）
- [ ] 护照风格在展示台点一下即应用（描边 + ✓，有触觉）；明信片样式/邮票选择仍在分享页内

## G. 订阅 / Lumi Plus 🔴
- [ ] 本地：scheme 设 StoreKit Configuration=`Lumi.storekit` 后，paywall 显示**月订一档 9.9**
- [ ] 购买后**立即变 Plus**；分享明信片页**打开即对齐权益**，无需再点订阅（曾需二次点击，已修，重点复验）
- [ ] 杀进程重开仍 Plus；「恢复购买」可用
- [ ] paywall 文案「开始订阅 / 每月·随时取消」三语正确

## H. 账户 / Sign in with Apple
- [ ] 设置页「账户」可用 Apple 登录；登录后显示姓名 + 退出登录（登录/登出有触觉）
- [ ] 未登录、英/阿界面：我的页顶部显示 **My World / عالمي**（不是中文「我的世界」）（已修，重点复验）

## I. 新版本提示 / 本次更新（零后端）
- [ ] **更新提示**：把本机 `MARKETING_VERSION` 临时调低于线上 → 启动弹「发现新版本 X.Y」→「去更新」跳 App Store；「跳过此版本」后不再弹；「稍后」下次仍弹；24h 内不重复；飞行模式/未上架→不弹不崩
- [ ] **本次更新**：全新安装→**不弹**（播种）；升 `MARKETING_VERSION` 或改 `lumi.lastWhatsNewVersion` 重开→弹一次；设置页「查看本次更新」可随时再看
- [ ] 设置页「关于」：当前版本 / 已是最新版本 / 有新版本可更新 三语正确

## J. 触觉反馈（真机；系统关「触感反馈」则无）
- [ ] 切 Tab、点亮足迹/国家、徽章解锁庆祝、收/寄明信片、心愿增删、相册导入完成、样式/置顶选择、登录登出 —— 均有合适震动

## K. 多语言（中 / 英 / 阿）

- [ ] （建议）阿语母语者最后通读一遍润色
